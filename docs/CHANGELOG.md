# Список изменений (Changelog)

Все значимые изменения в этом проекте документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
и проект следует [Семантическому версионированию](https://semver.org/lang/ru/).

## [Unreleased]

## [0.4.0] - 2026-11-14

### Изменено
- **Breaking:** Из конструктора `Transcriber` удалены параметры путей (`translit_rules_path`, `eng_to_ipa_rules_path`, `en_dict_path`). Теперь пути к скомпилированным `.pkl` файлам жестко зашиты внутри пакета. Использование словаря теперь максимально простое: `Transcriber(custom_vocabulary={...})`.

## [0.3.3] - 2026-11-13

### Исправлено
- Исправлено неправильное произношение некоторых слов в словаре (`every`, артикль `a`).

### Документация
- Русская версия README стала основной (теперь отображается по умолчанию на GitHub и PyPI).
- Обновлены примеры в README, чтобы они в точности соответствовали реальному выводу библиотеки.

## [0.3.2] - 2026-11-09

### Документация
- Исправлена атрибуция данных: словарь IPA взят из `open-dict-data/ipa-dict` (MIT), а не из OpenWiktionary.

## [0.3.1] - 2026-11-08

### Документация
- Примеры в README исправлены и теперь соответствуют реальному выводу.

## [0.3.0] - 2026-11-07

### Изменено
- **Breaking:** Параметры конструктора `Transcriber` переименованы:
  - `rules_path` → `translit_rules_path`
  - `eng_rules_path` → `eng_to_ipa_rules_path`
  - `dict_path` → `en_dict_path`
  - `cache_dir` → удален
- **Breaking:** Методы `Transcriber.reload_rules()`, `reload_dictionary()`, `reload_all()`, `clear_cache()` и `get_vocabulary()` удалены. Для применения новых правил создайте новый экземпляр `Transcriber`.
- Все ресурсы загружаются один раз в `__init__`. Конструктор либо возвращает полностью готовый объект, либо выбрасывает исключение.
- Удален модуль `phonetic_normalizations`. Вся логика нормализации (дифтонги, r-гласные) перенесена в `transliteration_rules.py`.

### Удалено
- Зависимость `platformdirs`. Теперь у библиотеки **0 зависимостей**.

### Производительность
- Транскрипция работает значительно быстрее, особенно для повторяющихся слов (благодаря внутреннему кэшированию). Обработка типичного предложения занимает менее миллисекунды.

## [0.2.3] - 2026-10-31

### Изменено
- `Transcriber` загружает правила и словарь в `__init__`, а не при первом вызове `transcribe()`.
- `repr(Transcriber())` выводит количество ресурсов вместо статуса загрузки.
- `clear_cache()` перекомпилирует правила сразу после удаления JSON-кэшей.

## [0.2.2] - 2026-08-02

### Документация
- Релиз только с обновлением документации для PyPI. Изменений в коде нет.

## [0.2.1] - 2026-06-27

### Изменено
- Библиотека `gruut` заменена на встроенный движок транскрипции на основе правил.
- Встроенный словарь сконвертирован из текстового формата в pickle для быстрой загрузки.

### Производительность
- Значительно ускорен запуск (нет загрузки внешних зависимостей).
- Время загрузки словаря снижено с ~200-400 мс до ~20-50 мс.
- Более точная транскрипция English-to-IPA с кастомными правилами.

### Удалено
- Зависимость `gruut` (больше не нужна).

## [0.2.0] - 2026-06-20

### Удалено
- Динамический API словаря: методы `add_exception()` и `remove_exception()`.
- Параметр `custom_exceptions` из метода `Transcriber.transcribe()`.

### Изменено
- **Breaking:** Параметр `custom_exceptions` переименован в `custom_vocabulary` в `Transcriber.__init__`.
- Пользовательский словарь теперь **статический** — задается один раз при создании объекта.
- Для разных наборов исключений создавайте разные экземпляры `Transcriber`.

### Документация
- Добавлена папка `docs/` с `ARCHITECTURE.md`, `CONTRIBUTING.md` и `DSL.md`.
- Добавлен русский перевод README (`README.ru.md`).
- Добавлено руководство по DSL для правил транслитерации.

### Руководство по миграции

**Было (0.1.1):**
```python
t = Transcriber()
t.transcribe("text", custom_exceptions={"kubernetes": "ˈkuːbərˌnɛtɪs"})
```

**Стало (0.2.0):**
```python
t = Transcriber(custom_vocabulary={"kubernetes": "ˈkuːbərˌnɛtɪs"})
t.transcribe("text")
```

## [0.1.0] - 2026-06-XX

### Добавлено
- Первый релиз.
