# Практическая англо-русская транскрипция

[Read in English](https://github.com/Isyarname/eng-to-ru-transcriber/blob/main/README.md)

Легковесная Python-библиотека для быстрой и предсказуемой практической транскрипции английских слов русским алфавитом.

## Зачем это нужно

**Библиотека создана для:**
- **Адаптации сленга и неологизмов** (например, *краш*, *вайб*, *хайп*).
- **Транскрипции имен, никнеймов и названий брендов.**

Современные инструменты перевода мощны, но для простых задач они избыточны:
- **Облачные API** (вроде Google Translate или DeepL) требуют подключения к интернету и имеют лимиты.
- **Нейросети** (даже локальные) — тяжелые, медленно загружаются и могут выдавать непредсказуемые результаты.

Иногда нужно просто мгновенно записать английские слова, имена или сленг русским алфавитом без ожидания загрузки моделей.

## Особенности

- **Практическая транскрипция:** адаптация IPA-звучания под правила русской орфографии, а не просто побуквенная замена.
- **Передача долготы гласных:** долгие гласные обозначаются знаком акута (например, `и́`, `у́`), что помогает сохранить фонетическую точность.
- **Без зависимостей и 100% офлайн:** никаких тяжелых ML-моделей и облачных API. Работает мгновенно.
- **Детерминированность:** одно и то же слово всегда дает идентичный результат.
- **Гибридный движок:** использует встроенный словарь на 120 000+ слов для частых слов и быстрый движок правил для всего остального.
- **Свой словарь:** легко научите библиотеку транскрибировать имена ваших персонажей, бренды или специфичные термины.

## Установка

Требуется Python 3.9 или выше.

```bash
pip install eng-to-ru-transcriber
```

## Использование

### Базовый пример

```python
from eng_to_ru_transcriber import Transcriber

t = Transcriber()
print(t.transcribe("Hello, URL!")) 
# → халоу, ю́а́эл!
```

*Аббревиатуры (например, URL) автоматически распознаются и читаются по буквам. Знак акута (например, `ю́`) обозначает долготу гласной, а не ударение.*

### Свой словарь

Вы можете легко переопределить произношение конкретных слов (имен, брендов или сленга), передав свой словарь:

```python
from eng_to_ru_transcriber import Transcriber

# Учим транскриптор вашим терминам
custom_vocabulary = {
    "python": "ˈpaɪθɑn",
    "kubernetes": "ˌkjuːbəˈnɛtɪs"
}

t = Transcriber(custom_vocabulary=custom_vocabulary)
print(t.transcribe("I love Python and Kubernetes"))
```
